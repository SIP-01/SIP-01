No secrets found. Findings are hygiene-only.

## Event Validation (audit focus)

- `parseIndexEvent` (reference): kind/structural checks + normalization; `verifyObservation` (async): `d == sha256(normalized u)` and `x == sha256(content)` — matches spec §18 step 2.
- Signature verification is **not** done inside the reference validator; it is delegated to the Nostr library/relay layer (nostr-tools `verifyEvent` is used in tests). This is acceptable for a reference library **provided the spec states readers/relays MUST verify `sig`** — recommend making that MUST explicit in NIP.md §18 reader guidance if not already.
