# Improvement Deep-Dive — SIP-01 — 2026-10-21

Scope: canonical spec + docs site + reference TS utils (`src/lib/sip01-utils.ts`). Findings grounded in files read this session: `public/spec/SIP-01.md`, `README.md`, `NIP.md`, `package.json`, `.github/workflows/deploy.yml`.

## Top recommendations (ranked, with effort S/M/L)

1. **Spec versioning process for kind 39697 — add CHANGELOG + git tags (S).** The spec is at v1.2 with a prose-only revision history in the header; there are no git tags or GitHub releases, so implementers cannot pin to `spec/v1.1` vs `spec/v1.2`, and the `v` tag in the event (currently `"1"`) has no documented bump policy tied to spec versions. Add `CHANGELOG.md` (wire-format changes vs documentation-only changes, mirroring the v1→v1.1 vs v1.1→v1.2 distinction already described in README), tag `spec/v1.2` retroactively, and document: "content-schema or tag-semantics change → `v` bump; editorial change → spec patch version only."
2. **Branch protection on `main` + PR-review gate (S).** `main` is unprotected (verified via branch list) and direct-to-main pushes are the norm across the org. For a NIP-candidate spec, require PR + 1 review for changes to `public/spec/SIP-01.md`. This is the single highest-leverage governance change.
3. **CI spec-consistency gate (S/M).** Only workflow is `deploy.yml` (build + Cloudflare Pages). v1 shipped an example its own relay would reject (placeholder hashes) — exactly what a test gate catches. Add a PR-triggered job: `vitest run` over §13 test vectors against `src/lib/sip01-utils.ts`, plus a markdown link checker (would have caught the stale org links below).
4. **Re-verify the §20.1 NIP dependency table against this week's upstream changes (S)** — see Ecosystem alignment.
5. **Fix stale `NostrDanish/*` links (S)** — see Hygiene.

## Quick wins (code/config)

- `src/lib/sip01-utils.ts` is documented as the byte-compatible reference that every implementation "lifts" — that is a distribution anti-pattern. Publish it as `@sip01/protocol` on npm/JSR with semver matching the spec version, so the §13 test-vector compatibility is enforced by a versioned artifact instead of copy-paste. (indexstr-v3 already aliases `@sip01/protocol` to a vendored `sip-01-core/` — proof the package wants to exist.) Effort M, kills a whole class of drift bugs.
- Add a JSON Schema (or zod schema export) for the kind 39697 content + tags so relays/engines can validate without porting prose. S.
